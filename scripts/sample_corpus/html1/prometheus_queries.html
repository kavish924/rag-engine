Prometheus Queries Reference (PromQL)

Query patterns for monitoring a RAG engine's API, retriever, and inference services — paired with Grafana dashboards.

Core PromQL Concepts

TermMeaning
counterMonotonically increasing value (e.g. total requests). Use rate()/increase(), never raw.
gaugeValue that goes up or down (e.g. memory usage, queue length).
histogramBuckets observations (e.g. request latency) — enables percentile queries.
rate()Per-second average rate of increase of a counter over a time window.
irate()Instant rate using only the last two data points — more reactive, noisier.

Request Rate & Traffic

counter

Requests per second (RAG API gateway)

rate(http_requests_total{job="rag-api"}[5m])
counter

Requests per second, broken down by endpoint

sum by (path) (rate(http_requests_total{job="rag-api"}[5m]))
counter

Error rate (5xx responses) as a percentage of total traffic

sum(rate(http_requests_total{job="rag-api", status=~"5.."}[5m]))
/
sum(rate(http_requests_total{job="rag-api"}[5m]))
* 100

Latency

histogram

p95 latency for the retriever service

histogram_quantile(0.95,
  sum by (le) (rate(retriever_request_duration_seconds_bucket[5m]))
)
histogram

p50 / p99 latency comparison for LLM inference calls

histogram_quantile(0.50, sum by (le) (rate(llm_inference_duration_seconds_bucket[5m])))
histogram_quantile(0.99, sum by (le) (rate(llm_inference_duration_seconds_bucket[5m])))
gauge

Average request duration over 5 minutes

rate(http_request_duration_seconds_sum{job="rag-api"}[5m])
/
rate(http_request_duration_seconds_count{job="rag-api"}[5m])

Resource Usage

gauge

CPU usage per Pod (with cAdvisor/kube-state-metrics)

sum by (pod) (rate(container_cpu_usage_seconds_total{namespace="rag-system"}[5m]))
gauge

Memory usage per Pod

sum by (pod) (container_memory_working_set_bytes{namespace="rag-system"})
gauge

GPU utilization (via DCGM exporter, for LLM/embedding inference)

avg by (gpu) (DCGM_FI_DEV_GPU_UTIL)

RAG-Specific Application Metrics

These assume you've instrumented custom metrics in your FastAPI app (via prometheus_client) for retrieval quality and hallucination tracking.

counter

Retrieval hit rate (fraction of queries with at least one relevant doc)

sum(rate(rag_retrieval_hits_total[15m]))
/
sum(rate(rag_retrieval_queries_total[15m]))

Hallucination flag rate (from an eval/guardrail check)

sum(rate(rag_hallucination_flagged_total[1h]))
/
sum(rate(rag_responses_total[1h]))
* 100

Vector DB query queue depth

vector_db_query_queue_depth{job="vector-db"}

Alerting Rule Examples

alert

High error rate

- alert: RagApiHighErrorRate
  expr: |
    sum(rate(http_requests_total{job="rag-api", status=~"5.."}[5m]))
    /
    sum(rate(http_requests_total{job="rag-api"}[5m])) > 0.05
  for: 5m
  labels:
    severity: critical
  annotations:
    summary: "RAG API error rate above 5%"
alert

Latency SLO breach

- alert: RetrieverLatencyHigh
  expr: |
    histogram_quantile(0.95,
      sum by (le) (rate(retriever_request_duration_seconds_bucket[5m]))
    ) > 1.5
  for: 10m
  labels:
    severity: warning
  annotations:
    summary: "Retriever p95 latency above 1.5s for 10 minutes"

Useful PromQL Functions Cheat List

FunctionPurpose
rate(v[t])Per-second average rate over range t (for counters)
increase(v[t])Total increase over range t
histogram_quantile(q, v)Compute percentile from histogram buckets
sum by (label) (v)Aggregate, grouped by a label
topk(n, v)Top n series by value
avg_over_time(v[t])Average value over range t
predict_linear(v[t], s)Linear-regression forecast s seconds ahead
absent(v)Returns 1 if series is missing — useful for "service down" alerts
Corpus note: pairs with the Kubernetes Services and Docker Networking references — Prometheus typically scrapes metrics endpoints exposed as ClusterIP Services inside the same cluster as the RAG engine's retriever, vector DB, and LLM inference Pods.
